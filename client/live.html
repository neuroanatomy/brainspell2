This is a test completely unrelated to brainspell.

This thing connects to the parse server sitting at brainspell.org. That parse server has live queries activated for the class RealTime. Here, the client subscribes to changes in RealTime matching {'name': 'T-Rex'}. Several event listeners are attached: open, enter, create, update.

The following buttons can be used to create data like {'name': [text]} (Enter Data); query data for objects that match {'name': 'T-Rex'} (Query Data), and to update data of the object that matches { 'name': 'T-Rex'} by adding {'impendingDoom': [text]}.

The results are displayed in the browser's console.
